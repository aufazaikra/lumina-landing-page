# 🚀 Lumina - Modern SaaS Landing Page

Lumina adalah project *landing page* modern untuk platform Software as a Service (SaaS) manajemen tugas. Project ini dibangun sepenuhnya menggunakan **HTML5 Semantic** murni dan **CSS3 Modern** tanpa *framework* eksternal untuk menunjukkan penguasaan dasar *web development*, *layouting*, dan desain yang responsif.

🌐 **Live Demo:** [https://aufazaikra.github.io/lumina-landing-page/](https://aufazaikra.github.io/lumina-landing-page/)

---

## ✨ Fitur Utama

- 📱 **Fully Responsive:** Tampilan menyesuaikan secara optimal di layar Mobile, Tablet, dan Desktop menggunakan Media Queries.
- 🎨 **Modern Layouting:** Memanfaatkan kombinasi **CSS Flexbox** untuk komponen 1D (Navbar, Buttons) dan **CSS Grid** untuk tata letak 2D (Features & Pricing).
- 🏷️ **Semantic HTML5:** Struktur dokumen yang rapi dan ramah SEO/Aksesibilitas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- 💎 **Interactive Micro-interactions:** Efek *hover*, transisi halus, dan animasi melayang (*floating effect*) pada kartu fitur dan paket harga.
- 🎯 **Clean Code:** Penggunaan CSS Custom Properties (Variables) dan CSS Reset (`box-sizing: border-box`).

---

## 🛠️ Tech Stack & Konsep yang Diterapkan

- **HTML5:** Semantic Elements, Form Control, Viewport Optimization.
- **CSS3:** Flexbox, Grid (`auto-fit`, `minmax`), Media Queries, CSS Variables, Transitions & Transforms.
